AFTERIMAGE: The Glass Reach
A free space shooter. A live game-development playground.

Dodge, collect salvage, bolt on extra lasers, and dive back into the stars.
Take a short three-sector run or keep flying in Endless mode. Press F1 to open Loupe,
the live inspector behind the game: change your ship, undo an experiment, keep playing.

Upload afterimage-itch-html5.zip as an HTML game. Enable fullscreen and use a 960 × 600
viewport with “Click to launch”. Keyboard and mouse required; desktop browsers recommended.
Set the price to free. Also offer Afterimage.love and afterimage-source.zip as downloads.
Controls: WASD/arrows move, Space pulse, Tab pause, M sound, F1 inspector.

This is a first playable release. Balance feedback is welcome, especially for later Endless cycles.

Building the upload (from the repository root):

  npm install --prefix .webtools love.js@11.4.1 ravensight@0.4.2
  RAVENSIGHT_PUBLIC_KEY=gt_pub_... python3 tools/build_itch.py --builder .webtools/node_modules/.bin/love.js
  python3 tools/audit_release.py --artifact dist/afterimage-itch-html5.zip

The zip's index.html contains the Ravensight public key by design (distribution "web-itch").
It is a public, write-only key with its own event allowlist and limits; anyone can read it from
the page, and it can be paused or revoked in Ravensight. The game inside is keyless and sends
nothing until the player switches ANALYTICS on. On an itch.io page the game runs in an iframe,
where the browser may block storage: the player's choice then lasts for that visit only.
Use the Afterimage.love from site/downloads (built with the key) and the source zip (never has
one). Without RAVENSIGHT_PUBLIC_KEY the build is keyless and sends nothing.

Suggested page note: "Optional, off by default: switch ANALYTICS on in the game to send anonymous
play stats (sectors, upgrades, deaths) to the developer."
