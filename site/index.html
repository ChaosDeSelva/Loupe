BUILD WITH AI. TUNE WITH YOUR HANDS.

Your idea.
Your hands on the controls.

Ask an assistant to build a game through Loupe’s local MCP server. Then open the running game, press F1, and keep shaping it yourself. Both of you use the same live values and undo history.

  1. 01

    Connect your assistant

    Install LÖVE 11.5 and Python 3.10+. Register mcp/server.py as a local stdio server in your MCP client. Point --project at an empty game folder and --love at your LÖVE executable.

  2. 02

    Give it a starting point

    Ask for game_scaffold with template: "afterimage" for the full shooter, or "minimal" for a blank start. Edit source, import your art and audio from an approved inbox, and build a .love file.

  3. 03

    Launch and take over

    Read the generated identity in conf.lua, set --bridge-dir to its save folder’s loupe-mcp directory, and reconnect. Ask for game_launch and loupe_status. Press F1, browse game → player, and tune speed or damage.

  4. 04

    Try it. Undo it. Keep it.

    Pause, step, resume and play. AI edits and your edits share Undo. Save keeps local overrides; ask the assistant to put your chosen defaults into source before shipping. Run the tests, play-test, then build again.

A complete example to remix

Story and Endless modes, visible upgrade stats, modular ship parts, original music, image backgrounds, centered menu buttons and keyboard navigation. It’s editable Lua, with tests included.

Helpers you can reuse

loupe.sprites plays looping and one-shot sprite sheets. loupe.collision checks fast projectile impacts. loupe.window handles window presets and fullscreen. The example demonstrates high-DPI layout and input scaling.

Fifteen local MCP tools

Discover capabilities, scaffold, read and write source, list and import assets, build, launch and stop, inspect and change live values, control undo/save, and capture screenshots.

Live MCP requires native LÖVE; the browser game still has the F1 inspector. Source and asset changes need a restart. Save writes local overrides, not source. Art generation happens in an external tool. Loupe needs no service key or hosted relay; your AI client may have its own account requirements. LÖVE supplies rendering, audio and rigid-body physics. Nothing is published automatically.
