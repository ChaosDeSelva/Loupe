## What changed, per file

### Library
- **`core/hook.lua`**: `install` was one 81-line function with seven closures. It's now three
  parts that share one `chain` state table: `wrapCallback` (the per-name wrapper with its
  `call`/`finish` bookkeeping), `assign` (the `__newindex` rule), and `install` (setup and the
  handle). Each state field is commented where it's declared. The old `links[name]` table became
  a local `callOriginal`, made once per name, so the function the wrapper passes is still the
  same function every call.
- **`core/reflect.lua`**: new `reflect.path(rootName, keys)`, which builds a whole Lua-style
  path. It replaces two copies of the same loop, in `geometry` (lazy `entry.path`) and
  `overrides.path`. New `reflect.resolveParent(root, keys)` replaces two more copies: the
  parent-key list built in `edits:retarget` and the hand-rolled parent walk in
  `overrides.apply`. `fields` builds its records with one `field(key, value)` helper instead of
  two identical table literals.
- **`core/geometry.lua`**: entry construction (copying the shared key stack, the metatable) moved
  to `newEntry`, so `collect`'s walk is only the walk.
- **`core/edits.lua`**: `undo` and `redo` repeated the same override-recording loop with
  old/new swapped. It's now one local `recordOverrides(self, step, from, to)`. `retarget` uses
  `resolveParent`.
- **`core/history.lua`**: the four-line merge condition is a named predicate, `continuesTop`.
  The default undo limit is a named constant, `DEFAULT_LIMIT`.
- **`core/serialize.lua`**: `write` handled scalars and tables in one function. Table writing is
  now `writeTable`, so `write` reads as a type dispatch. The unknown-type `error` sits at the end
  of the dispatch instead of in the middle of an `elseif` chain.
- **`core/overrides.lua`**: `path` and `apply` use the new reflect helpers (−7 lines).
- **`storage.lua`**: the save/set/restore of the count hook is now `runLimited(chunk)`, so
  `parse` reads as the checks it makes. The bytecode check uses a named `BYTECODE_MARK` instead
  of a bare `27`.
- **`reload.lua`**: the "find the file once, then stat it" logic moved out of `check` into a
  local `modtimeOf`. `check` has a doc comment, and a comment says why `shared` is built lazily.

### Examples
These have never run in LÖVE, so I only made clarity changes. No tunable values changed. To
check that, I wrote a throwaway headless harness (a permissive `love` stub, loupe stubbed out, a
fixed RNG seed, scripted input: Enter, then alternating held keys and jump presses). It runs each
game for 3000 frames and dumps the whole `game` table. The dumps from the original and the
refactored code are **byte-identical** for both games. Asteroids ends in game over after deaths
and waves; the platformer collects coins, dies and respawns. Identical dumps also show the order
of `love.math.random` calls didn't change. The harness isn't committed: it isn't LÖVE, and the
smoke run in real LÖVE is still owed.

- **`shared/smoke.lua` (new)**: the `--smoke [frames]` parsing and countdown was copied into
  each `main.lua`. It's now `smoke.start(args)` and `smoke.tick()`. `ui_gallery` has a third
  copy, but that file belongs to the UI agent, so it can switch to this helper later.
- **`asteroids/main.lua`**: uses `smoke`. The wave timer and banner logic moved to
  `updateWaves`. `1 / 30` is `MAX_DT`. `destroyRock` computes `size = rock.r / fx.BIG_RADIUS`
  once instead of writing `/ 40` twice.
- **`asteroids/src/fx.lua`**: `BIG_RADIUS = 40` names the radius that effects are sized for.
  `explode` and `main` use it.
- **`asteroids/src/rocks.lua`**: `local next` shadowed the builtin `next`, so it's now
  `smaller`. `rocks.color(rock)` replaces two copies of `rock.def.color or { 1, 1, 1, 1 }`.
  `OUTLINE_POINTS` names the 11.
- **`asteroids/src/ship.lua`**: `update` is split into `steer` (input and thrust) and `slow`
  (drag and speed cap).
- **`asteroids/src/hud.lua`**: `draw` is split into `drawBanner`, `drawTitle` and
  `drawGameOver`. The duplicated blink formula is `blink()`, and the unit snapping is
  `unitFor(w, h)`.
- **`platformer/main.lua`**: uses `smoke`. `MAX_DT`.
- **`platformer/src/player.lua`**: `update` (65 lines) is now five named steps:
  `inputDirection`, `run`, `tryJump`, `fall` and `move`/`animate`. Constants replace the bare
  numbers: `AIR_COAST` (0.4), `FULL_SQUASH_LANDING` (500), `SQUASH_RECOVERY` (14). New
  `player.stretch(p)` is the take-off stretch. It was duplicated in `world`'s stomp bounce.
- **`platformer/src/world.lua`**: `new` no longer embeds the fx tunables (`newFx()`) or the coin
  layout (`COIN_SPOTS` and `newCoins()`). The spawn point was written twice (`40, 260`) and is
  now `SPAWN_X, SPAWN_Y`. `update`'s 50-line else branch is now `updatePlayer`, with
  `playerEffects` (dust and sounds) and `reachFlag` (confetti). Constants replace the bare
  numbers: `RESPAWN_DELAY`, `FALL_MARGIN`, `POPUP_LIFE` (it was 0.8 in two places that had to
  agree), `CELEBRATION_LENGTH`, `HARD_LANDING`, `FULL_DUST_LANDING` and `RUN_DUST_SPEED`. The
  firework palette used to be rebuilt on every firework and is now a module constant.
- **`platformer/src/backdrop.lua`**: tree drawing is split out of `drawLayer` into `drawTrees`.
- **`platformer/src/hud.lua`**: the blink formula is in a `blink(time)` helper.
- **`platformer/src/text.lua`**: removed `text.width`, which nothing called (dead code).

## Specs
- **New:** `reflect.path` and `reflect.resolveParent` each have a spec. I wrote them alongside
  the helpers rather than strictly first. The helpers came out of existing code, which the
  existing specs already covered through `geometry`, `overrides` and `edits`.
- **Strengthened:**
  - `hook` "remove is safe to call twice" only checked that the second call didn't throw. It
    now also checks that the metatable is gone and the game's callback is back on the table.
  - `hook` "refuses a table that already has a metatable" accepted any error. It now checks the
    message, and that the host's callback wasn't moved off the table.
  - `storage` "reports syntax errors" accepted any truthy `err`. It now checks that the error
    names `loupe_overrides.lua:1:`, which is the chunk name the code sets on purpose.
  - `registry` "unwatches by name": unwatching a missing name only checked that it didn't
    throw. It now also checks that the remaining watch is still there.

## Bugs found
None. Every refactor passed the full suite on the first run. The example dumps matched before
and after.

## Not changed, and why
- `hotswap.lua`, `clock.lua` and `registry.lua` were already small, single-purpose and
  commented. I found nothing to improve that wouldn't just be my taste.
- `hook.install` is still 45 lines. Most of that is the commented `chain` state table and the
  two-function `handle`. Splitting it further would add indirection without making it clearer.
- Long `draw` functions in the examples (`player.draw`, `enemies.draw`, `ship.draw`,
  `fx.shipExplosion`) are straight-line drawing and particle presets. Splitting them would
  scatter magic coordinates without making them clearer.
- Error message prefixes stay as they are. `loupe.watch:`, `loupe.serialize:` and `loupe:` all
  start with "loupe", and init.lua (not mine) depends on some of the wording.
