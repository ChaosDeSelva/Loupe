# 1.1: UI redesign (docked layout, themes, fonts)

- Date: 2026-10-09
- Author: Claude Code (Opus 5.5); reviewer: maintainer
- Status: done, awaiting maintainer review (ran in parallel with the hardening agent)

## What was built
- `ui/theme.lua`: spacing scale, radii, color roles (surface, surfaceRaised, field, control,
  border, text, textMuted, textFaint, accent, accentSoft, selection, focus, warning, danger,
  success, ...) and font roles (body, strong, small, title, mono). `theme.build(overrides,
  scale)` returns a merged, scaled, independent copy; the module itself is the scale-1 default.
- `ui/render_love.lua`: font roles with bundled Inter / JetBrains Mono subsets, loaded through
  `love.filesystem` (module-relative) or `io` + `newFileData` (package.path installs), falling
  back to LÖVE's default font on any failure; fonts re-rasterized when `getDPIScale()` changes;
  rounded rects/outlines, `line`, `circle`, `poly`; replay inside `pcall` so `pop()` always
  runs, then the error is re-raised.
- `ui/context.lua`: docked and popover windows (rect applied every frame, no drag, never
  brought to front), floating windows clamped on screen, splitters, a draggable auto-hiding
  scrollbar with a gutter, auto-height fix-up in the same frame, `rectOf(id)`, font-aware
  `fitText` (binary search) and `fitTextStart` (keeps the end, for paths).
- `ui/layout.lua`: wrap for `sameLine` items that don't fit, `alignRight`.
- `ui/widgets.lua`: restyled everything; new `toggle`, `segmented`, `divider`, `spacer`,
  `pathLabel`, `valueRow`, `buttonWidth`/`toggleWidth`; button options (primary, quiet,
  icon, disabled, selected); vector icons; focus ring; integer-aware `dragNumber` with Shift
  for fine steps; tree counts and selection pill; color swatch with hex.
- `panels/layout.lua` (new, pure): bar / sidebar / Objects / Inspector / free rects and
  splitter handles from screen size, theme and splitter state.
- `panels/toolbar.lua` is now the top bar (one row, or two when narrow) with a "?" key
  popover; `objects`/`inspector` are docked sections with headers and counts; `badge` is a
  themed pill plus a wrapped alert card; `core/picker.lua` `highlight` draws a rounded outline,
  a soft fill and a path pill clamped and clipped to the free area.
- `init.lua`: `drawOverlay` body, the layout module in place of `sidePanelRects`, theme/scale
  sync, splitter dragging, resize cursor, `attach({ theme, uiScale })`, `loupe._debugUi()`.
- `examples/ui_gallery` uses the new API and shows the new widgets.

## Numbers

files. Fonts: Inter-Regular 66.6 KB, Inter-SemiBold 68.0 KB, JetBrainsMono-Regular 28.7 KB

## Test-first evidence
theme, render_love, panels/layout, toolbar and badge specs failed on missing functions or
modules first. The ui/layout wrap and alignRight specs failed (1 failure, 2 errors) before the
change. New context specs (gutter, auto-height popover clip) were written after screenshots
showed the bugs and failed against the code that had them.

## What the gates and checks caught
1. **The help popover was clipped to two rows (caught by a screenshot).** A docked window
   took `rect.h` every frame, so the clip used the stale small height even though the
   background grew. Auto-height docked windows now keep their fitted height and don't clip
   vertically; a spec covers it.
2. **Scrollbars overlapped values and counts (screenshot).** Overflowing windows now reserve
   a gutter.
3. **Game HUD text showed through the panels (screenshot).** Surface alpha raised to 0.975.
4. **Color channels would have snapped to 0/1** under the new integer-aware drag (a channel
   at 1 is a whole number). The inspector passes `integer = false`; a spec drags alpha from 1.
5. **Three wrong expectations in the AI's own specs**: a splitter grab offset sign, a
   `fitTextStart` width that fit exactly, and expecting `held == false` on the release frame.
6. **A stray global assignment** (`item = nil`) in the first toolbar draft, removed before
   luacheck ran; luacheck caught an unused assignment in the badge wrapper and an unused
   `colors` local left in `picker_spec`.
7. The worktree sandbox refused several compound shell edits; edits were redone one at a time.

## Verification beyond unit tests
A scratch harness (outside the repo) loaded asteroids, platformer and ui_gallery from this
worktree with a custom `love.run`, opened the overlay, selected objects through
`loupe._debugUi()` rects, resized to 960x640, 1600x900, 1100x620 (help open), desktop
fullscreen and 700x520, and saved PNGs. Three iterations, including `highdpi = true`
(3456x2160 capture: text crisp) and one run with `loupe/fonts` removed (default font, layout
intact). `love examples/<game> --smoke 120` exits 0 for all three examples.

## Known limitations
- The game draws full size underneath; the sidebar covers part of it while the overlay is open.
- The auto UI scale is a height heuristic; set `uiScale` explicitly if it guesses wrong.
- No hover fades; the luarocks install has no fonts (falls back to the default font).
