# 1.1.1 integration and release (lead agent)

- Date: 2026-10-09
- Author: Claude Code (Opus 5.5), lead agent; reviewer: maintainer
- Status: done; tagged `v1.1.1` locally. Manual checklists not yet confirmed by the maintainer.

## What happened
The maintainer asked whether 1.1 was "100% done". It wasn't, so the remaining gaps were listed
and closed by three parallel agents plus the lead:
- **UI finish** (`1.1.1-ui-finish.md`): strings with newlines/control characters on one row and
  edited escaped; clean dragged numbers; selection and clipboard in fields; key releases and
  hotkey text no longer reach the game.
- **Portability** (`1.1.1-portability.md`): the suite passes on PUC Lua 5.1.5 built from source;
  the CI workflow's steps pass on Linux (Docker, arm64 and emulated amd64) with LÖVE 11.5 under
  Xvfb; shortest-form number serialization.
- **Docs** (`1.1.1-docs.md`): the toolkit reference rewritten from the code; changelog, keys,
  input routing, checklists.
- **Lead:** fullscreen verified in real LÖVE on macOS; release, builds, packaging.

## What the lead caught
1. **Shift fine-drag didn't work in `ui_gallery`** (found by the docs agent reading the code):
   the gallery never put shift state in the input snapshot. Fixed.
2. **The rockspec was missing the new `loupe.ui.escape` module** (found by the lead's manual
   module check), so a LuaRocks install would fail at `require` time. This was the second release
   where a new module was missed, so `tools/check.sh` now fails whenever the rockspec and the
   files on disk disagree.
3. Stale toolkit comments: the button icon list and the `loupe.ui` header example.

## Builds
`tools/build.sh` (new) packs each example with loupe and the shared helpers inside, as a
`.love` and a macOS `.app`. All six builds were smoke-run: each `.app` as a real fused game and
each `.love` through LÖVE, with loupe's overlay open, all exiting 0 with no errors.

## Fullscreen (real LÖVE, macOS, Retina)
F11 with loupe open: the window went to 1728x1080, the top bar followed to the full width, and
the sidebar grew from 296 to 411 px (its proportional default). F11 again restored 960x640 and the
original layout.

## Numbers
552 specs on LuaJIT and PUC Lua 5.1.5. Coverage: `core/` 99.5%, `ui/` 99.4%. 0 luacheck warnings
across 87 files. 28 modules.
