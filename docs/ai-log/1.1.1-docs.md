## Doc/code mismatches found (read against the code, not the logs)
1. **Old toolkit docs were 1.0:** single-argument `measure(text)`, `lineHeight` as a number
   only, `render.lineHeight()` called with no role in the wiring example, a `theme` that
   "replaces" `loupe.ui.theme` (it must be a built theme; the module is the scale-1 default),
   `beginFrame(snapshot)` without the screen size, a `rect`-only window description, five draw
   command kinds without `radius`/`width`/`font`, and "No selection or clipboard".
2. **Missing widgets and methods:** `toggle`, `toggleWidth`, `segmented`, `divider`, `spacer`,
   `alignRight`, `buttonWidth`, `pathLabel`, `valueRow`, `splitter`, `rectOf`, `setTheme`,
   `setMetrics`, `fitText`/`fitTextStart`, `oneLine`, `glyphs`, `ellipsis`; `label` takes a
   font role as a third argument.
3. **Undocumented `beginWindow` options in code:** `header = false` (a `nil` title does the
   same) and `surface`. Neither was in the brief's list; both are documented now.
4. **Button icons:** the comment above `W:button` lists five icons, but the code also draws
   `chevronRight`, `chevronDown` and `check`. The reference lists all eight. Button options
   `color` and `font` were also uncommented.
5. **Shift fine-drag isn't fed by `ui.newInput()`.** `dragNumber` reads `snapshot.shift`, which
   `input:frame()` never sets; loupe's `init.lua` sets it from `love.keyboard.isDown`.
   `examples/ui_gallery` doesn't set it, so **Shift fine-drag doesn't work in the gallery**
   (only Shift for selection does, through the key mods). The wiring example in the docs adds
   the one line; the gallery itself needs a code change (out of scope here).
6. **Version strings still say 1.1.0:** `loupe._VERSION` in `loupe/init.lua` and
   `loupe-1.1.0-1.rockspec`. Left for the lead's version bump.
7. **Theme colors not drawn by the toolkit:** `titleBar` isn't used anywhere in loupe;
   `accentSoft` is only the world picker's fill; `danger` is unused. The color table says so
   rather than inventing uses.
8. **Doc-comment in `loupe/ui/init.lua`** still shows `measure = function(text)` and
   `lineHeight = font:getHeight()`. Still valid usage (a number, and the role argument
   ignored), so not wrong, just dated; not changed (no `.lua` edits).
9. `escape.oneLine` writes `\r` as `\r` too, not only `\n`/`\t`; documented.
